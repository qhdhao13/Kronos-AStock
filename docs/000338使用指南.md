# 潍柴动力（000338）Kronos 使用指南

本文档说明如何在本地使用 Kronos 项目分析 **000338（潍柴动力）** 日 K 线，包括：数据下载、Web 界面回测、微调模型前瞻预测，以及重新训练流程。

> **重要提示**：Kronos 输出的是统计意义上的 K 线预测，**不构成投资建议**。请勿将预测结果直接用于实盘交易。

## 1. 项目能做什么

| 功能 | 工具 | 用途 |
|------|------|------|
| **回测对比** | Web UI（`webui/app.py`） | 用历史 400 根 K 线预测，再与后 120 根真实 K 线对比，评估误差 |
| **前瞻预测** | `examples/predict_000338_finetuned.py` | 用**已微调的 000338 模型**，从最新收盘价往后预测 120 个交易日 |
| **模型微调** | `scripts/finetune_000338.sh` | 用本地 CSV 在 Kronos-small 上继续训练，使模型更贴近 000338 |

**为什么分两种方式？**

- Web UI 默认加载 HuggingFace **预训练** Kronos-small，适合看「模型在历史窗口上准不准」。
- 微调脚本加载 **本地微调权重**，适合看「从今天往后大概怎么走」（仍是参考，非精确预报）。

## 2. 环境准备

### 2.1 系统要求

- macOS（当前环境已验证 Apple MPS 加速）
- Python 3.10+（项目使用 3.12 虚拟环境）
- 磁盘空间：模型缓存约 1～2 GB，微调产物约数百 MB

### 2.2 首次安装

在项目根目录执行：

```bash
cd /Volumes/disk-hfm/Kronos

# 创建并激活虚拟环境
python3 -m venv .venv
source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt
pip install flask flask-cors plotly akshare pyyaml

# HuggingFace 镜像（国内下载模型必需）
export HF_ENDPOINT=https://hf-mirror.com
```

建议将镜像写入 shell 配置，避免每次手动设置：

```bash
echo 'export HF_ENDPOINT=https://hf-mirror.com' >> ~/.zshrc
```

### 2.3 每次使用前

```bash
cd /Volumes/disk-hfm/Kronos
source .venv/bin/activate
export HF_ENDPOINT=https://hf-mirror.com
```

## 4. 第一步：准备数据

所有功能都依赖同一份 CSV：`data/000338_daily_qfq.csv`。

### 4.1 通过 Web UI 下载（推荐）

1. 启动 Web UI（见下一节）。
2. 在左侧 **「下载 A 股数据」** 区域：
   - 股票代码：`000338`
   - 周期：**日 K**
   - 复权：**前复权（推荐）**
3. 点击 **「下载并更新数据」**。
4. 下载完成后，在 **「选择数据文件」** 中选择 `000338_daily_qfq.csv`，点击 **「加载数据」**。

### 4.2 CSV 格式要求

| 列名 | 说明 |
|------|------|
| `timestamps` | 日期，如 `2026-06-02` |
| `open` / `high` / `low` / `close` | 开高低收 |
| `volume` | 成交量 |
| `amount` | 成交额 |

### 4.3 更新频率建议

- **日常看预测**：每个交易日收盘后更新一次 CSV，再跑前瞻预测脚本。
- **股价形态变化较大**（如长期暴涨后）：建议重新微调（见第 7 节）。

## 5. 方式 A：Web 界面（回测对比）

### 5.1 启动

```bash
cd /Volumes/disk-hfm/Kronos/webui
source ../.venv/bin/activate
export HF_ENDPOINT=https://hf-mirror.com
python app.py
```

浏览器打开：**http://localhost:7070**

若端口被占用，可先结束旧进程：

```bash
lsof -i :7070
kill <PID>
```

### 5.2 操作流程

按以下顺序操作：

```
加载数据 → 对齐最新窗口 → 加载模型 → 开始预测 → 查看图表与对比表
```

**详细步骤：**

1. **加载数据**  
   选择 `000338_daily_qfq.csv`，点击「加载数据」。  
   确认「数据信息」中时间范围包含最新交易日。

2. **时间窗口**  
   - 固定窗口：**400 根输入 + 120 根对比 = 520 根 K 线**。  
   - 点击 **「对齐最新数据」**，或手动将滑块拖到**最右侧**。  
   - 窗口结束日期应接近 **2026-06-02**（以你 CSV 最新日期为准）。  
   - 界面会显示：`窗口：YYYY-MM-DD ～ YYYY-MM-DD（第 x～y 根）`。

3. **加载模型**  
   - 模型选择：**Kronos-small**（默认即可）。  
   - 设备：Mac 可选 CPU 或 MPS。  
   - 点击「加载模型」，等待 HuggingFace 下载完成（首次较慢）。

4. **开始预测**  
   - 点击「开始预测」，等待约 1～3 分钟。  
   - 页面会显示：K 线图表、分析结论、预测 vs 真实对比表、MAE/RMSE/MAPE。

### 5.3 如何理解 Web UI 结果

| 区域 | 含义 |
|------|------|
| 绿色/蓝色 K 线 | 输入段（400 根历史） |
| 预测 K 线 | 模型根据输入段生成的 120 根 |
| 真实 K 线 | 同一窗口内后 120 根实际行情（回测用） |
| 对比表 | 同一交易日下，预测 OHLC vs 真实 OHLC |
| MAPE 等 | 误差指标，越小越好（暴涨股往往仍偏大） |

**注意**：这是 **回测**，不是「从现价 32 元猜未来」。对比表最后一行应对齐 CSV 最新日期附近。

### 5.4 Web UI 使用的模型

当前 Web UI 加载的是 **HuggingFace 预训练 Kronos-small**，**不是**本地微调模型。  
若要用微调模型做可视化，请使用 [方式 B](#6-方式-b微调模型前瞻预测) 或查看 `examples/outputs/` 下的图表。

## 6. 方式 B：微调模型（前瞻预测）

适用于：**从最新收盘价往后看 120 个交易日** 的参考走势。

### 6.1 前提

已完成微调，且存在以下目录：

```
finetune_csv/finetuned/000338_daily_qfq/tokenizer/best_model/
finetune_csv/finetuned/000338_daily_qfq/basemodel/best_model/
```

若不存在，请先执行 [第 7 节](#7-重新微调数据更新后) 微调流程。

### 6.2 运行预测

**方式 1：自动（推荐）** — 有本地权重用本地，否则从 Hugging Face 下载：

```bash
python examples/predict_000338_finetuned.py
```

**方式 2：直接从 Hugging Face 加载**（无需本地微调，约 110MB 下载）：

```bash
python examples/predict_000338_finetuned.py --from-hub
```

公开模型地址：

| 组件 | Hugging Face |
|------|----------------|
| Tokenizer | [qhdhao13/Kronos-000338-Tokenizer](https://huggingface.co/qhdhao13/Kronos-000338-Tokenizer) |
| Predictor | [qhdhao13/Kronos-000338-small](https://huggingface.co/qhdhao13/Kronos-000338-small) |

国内建议：

```bash
export HF_ENDPOINT=https://hf-mirror.com
```

### 6.3 输出文件

| 文件 | 说明 |
|------|------|
| `examples/outputs/pred_000338_finetuned_forward.csv` | 未来 120 根 K 线（开高低收、量额） |
| `examples/outputs/pred_000338_finetuned_forward_chart.png` | 历史收盘 + 预测收盘曲线 |

终端会打印：

- 输入区间（最近 400 根）
- 预测区间（未来 120 个交易日）
- **末日预测收盘价**（仅供参考）

### 6.4 脚本参数说明（需改代码）

编辑 `examples/predict_000338_finetuned.py` 顶部常量：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `LOOKBACK` | 400 | 输入历史 K 线根数 |
| `PRED_LEN` | 120 | 向前预测根数 |
| `DEVICE` | `"mps"` | Mac GPU；报错可改为 `"cpu"` |
| `DATA_PATH` | `data/000338_daily_qfq.csv` | 数据文件 |

### 6.5 典型工作流（长期跟踪 000338）

```
每个交易日收盘后：
  1. Web UI 下载更新 CSV
  2. python examples/predict_000338_finetuned.py
  3. 打开 examples/outputs/pred_000338_finetuned_forward_chart.png 查看

每季度或大涨大跌后：
  bash scripts/finetune_000338.sh   # 重新微调约 2 小时
  再运行预测脚本
```

## 7. 上传微调权重到 Hugging Face（维护者）

若希望他人**跳过本地微调**直接下载权重，可将 `best_model` 上传到 Hugging Face。

### 7.1 登录

在 [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) 创建 **Write** 权限 Token，然后：

```bash
huggingface-cli login
# 或：export HF_TOKEN=hf_xxxxxxxx
```

### 7.2 一键上传

```bash
cd /Volumes/disk-hfm/Kronos
bash scripts/upload_000338_to_hf.sh
```

仅检查路径、不上传：

```bash
python scripts/upload_000338_to_hf.py --dry-run
```

上传后公开地址：

| 组件 | Repo ID |
|------|---------|
| Tokenizer | `qhdhao13/Kronos-000338-Tokenizer` |
| Predictor | `qhdhao13/Kronos-000338-small` |

### 7.3 他人如何使用 HF 权重

```bash
export HF_ENDPOINT=https://hf-mirror.com   # 国内可选
python examples/predict_000338_finetuned.py --from-hub
```

## 8. 重新微调（数据更新后）

### 8.1 一键微调

```bash
cd /Volumes/disk-hfm/Kronos
bash scripts/finetune_000338.sh
```

或手动：

```bash
cd /Volumes/disk-hfm/Kronos/finetune_csv
source ../.venv/bin/activate
export HF_ENDPOINT=https://hf-mirror.com
python train_sequential.py --config configs/config_000338_daily_qfq.yaml
```

### 8.2 训练配置摘要

配置文件：`finetune_csv/configs/config_000338_daily_qfq.yaml`

| 项 | 值 |
|----|-----|
| 基座模型 | Kronos-small |
| 输入 / 预测窗口 | 400 + 120 |
| 训练 / 验证划分 | 85% / 15%（按时间顺序） |
| Tokenizer 轮数 | 20 |
| Predictor 轮数 | 15 |
| 设备 | MPS（Apple GPU） |
| 预计耗时 | 约 **2 小时**（M 系列 Mac） |

### 8.3 查看训练进度

```bash
tail -f finetune_csv/finetuned/000338_daily_qfq/logs/tokenizer_training_rank_0.log
tail -f finetune_csv/finetuned/000338_daily_qfq/logs/basemodel_training_rank_0.log
```

成功结束时日志会出现：

```
Training completed!
Tokenizer model: .../tokenizer/best_model
Basemodel model: .../basemodel/best_model
```

### 8.4 跳过已训练阶段

若 Tokenizer 已存在，只训 Predictor：

```bash
python train_sequential.py --config configs/config_000338_daily_qfq.yaml --skip-tokenizer
```

若模型都已存在且不想重训：

```bash
python train_sequential.py --config configs/config_000338_daily_qfq.yaml --skip-existing
```

## 10. 常见问题

### Q1：对比表日期只到 2024 年，不是最新？

- 检查时间滑块是否点了 **「对齐最新数据」**。
- 强制刷新浏览器（Cmd+Shift+R）。
- 确认加载的是 `000338_daily_qfq.csv`，不是其他股票文件。

### Q2：预测价和真实价差很多（如 32 vs 10）？

- Web UI 回测：Kronos-small 对暴涨段误差大属常见现象。
- 前瞻脚本：微调后会更贴近 000338，但仍可能偏空或偏差大，**不能当精确目标价**。

### Q3：HuggingFace 下载失败？

```bash
export HF_ENDPOINT=https://hf-mirror.com
```

然后重试加载模型。

### Q4：微调脚本报「未找到微调模型」？

先完成微调：

```bash
bash scripts/finetune_000338.sh
```

确认 `finetune_csv/finetuned/000338_daily_qfq/basemodel/best_model/` 存在。

### Q5：MPS 报错，改用 CPU

在 `predict_000338_finetuned.py` 中设置：

```python
DEVICE = "cpu"
```

微调配置 `config_000338_daily_qfq.yaml` 中可设：

```yaml
device:
  use_cuda: false
  use_mps: false
```

### Q6：000338 前复权早期价格为负？

前复权在除权除息较多时，早期价格可能为负，这是复权算法正常现象；Kronos 仍可使用，但早期段对预测影响较小（训练主要用近期形态）。

### Q7：能否用于其他 A 股？

可以。流程相同：

1. Web UI 下载对应代码 CSV  
2. 复制 `config_000338_daily_qfq.yaml` 并修改 `data_path`、`exp_name`  
3. 复制并修改 `predict_000338_finetuned.py` 中的路径与文件名
